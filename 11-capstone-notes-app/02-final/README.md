# Lab 11 · Capstone Notes App — solusi

Ini adalah **solusi lengkap dan sudah berjalan** untuk lab ini. Gunakan
untuk mengecek hasil pekerjaanmu setelah menyelesaikan `01-start`, atau
baca dulu kalau kamu lebih suka mempelajari contoh jadi sebelum menulis
kode sendiri.

Penjelasan lengkap, tujuan pembelajaran, dan instruksi langkah demi
langkah ada di [README.md](../README.md) lab ini.

Jalankan dengan:

```bash
flutter pub get
flutter run
```
